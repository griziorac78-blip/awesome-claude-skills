# Modèles de sortie

## 1. Tableau récapitulatif (après un SCAN)

```
| # | Compte | Vues | Abonnés | ×Outlier | like% | comm% | save% | share% | Score | Classe | Hook | Format | Son |
|---|--------|------|---------|----------|-------|-------|-------|--------|-------|--------|------|--------|-----|
| 3 | @...   | 2,1M | 24k     | ×87      | 9,1   | 0,21  | 1,4   | 1,1    | 82    | 🔥     | H-ERREUR | F-TUTO | M-SYNC |
```

Trie par Score décroissant. Ajoute sous le tableau 3 observations immédiates (ce qui saute aux yeux).

## 2. Banque de Patterns

```markdown
# Banque de Patterns — [niche] · [pays/langue] · v[N] · [date]
Basée sur [X] vidéos ([Y] 🔥 / [Z] ❌). Sources : [captures / navigateur / CSV].

## 🏆 Recette gagnante (résumé en 5 lignes)
Hook : ...
Format : ...
Durée : ...
Son : ...
Levier : ...

## Patterns (du plus fort au plus faible)

### P1 — [Nom court]  · confiance : élevée / moyenne / hypothèse
- Vu dans : [n]/[Y] outliers · Score moyen avec : [a] vs sans : [b]
- Règle : [formule actionnable, avec placeholders]
- Exemples : « ... » (@compte, vues, ×outlier)
- Comment l'appliquer : [1 phrase]

### P2 — ...

## 🎵 Sons à surveiller
| Son | Vu dans | Énergie | Drop à | Statut (montant / au pic / en baisse / ?) |

## ⛔ Anti-patterns
- A1 — [ce qu'on retrouve dans les flops] · vu dans [n]/[Z] flops

## 🧪 Hypothèses à tester
- [pattern pas encore confirmé + comment le tester]

## Journal des mises à jour
- v1 [date] : création ([X] vidéos)
```

À chaque mise à jour : incrémente la version, ajuste les compteurs, rétrograde en « hypothèse » ce qui n'est plus confirmé, supprime ce qui a été contredit 2 fois.

```markdown
| C | ... | ... | ... |

### Déroulé
| Temps | Plan / action | Voix off / dialogue | Texte à l'écran | Son / transition |
|-------|---------------|---------------------|-----------------|------------------|
| 0–2 s | ... | ... | ... | ... |
| 2–5 s | ... | ... | ... | ... |
| ...   | ... | ... | ... | ... |
| fin   | (boucle → renvoie à 0 s) | ... | ... | ... |

### Son
Type : ... · Énergie/BPM : ... · Caler le drop sur : ... · Suggestion : [son vu dans les données ou « chercher dans la bibliothèque TikTok : ... »]

### Publication
Légende : ...
Hashtags : #... #... #... (niche + large)
Mots-clés à dire/écrire (SEO TikTok) : ...
CTA : ...
Commentaire épinglé à poster : ...

### Checklist tournage
- [ ] Format vertical 9:16, sujet dans le tiers central
- [ ] Hook lisible en < 1 s sans le son
- [ ] Texte hors des zones couvertes par l'interface (bas et droite)
- [ ] Coupe toutes les 1–3 s (si format rapide)
- [ ] Payoff avant la dernière seconde, fin qui reboucle
- [ ] Sous-titres

### Test
Variable testée : ... · Mesurer à 24 h et 48 h : vues, % visionnage complet, share%, save%
```
