# Bibliothèque de patterns TikTok

Ces étiquettes servent à classer chaque vidéo de la même façon pour pouvoir les comparer. Utilise le code (ex. `H-CURIO`) dans les fiches et la Banque de Patterns. Si une vidéo ne rentre dans aucune case, crée une étiquette `X-...` et décris-la.

Ce sont des patterns génériques observés sur la plateforme. Ils servent de point de départ : ce sont les données réelles de la niche de l'utilisateur qui décident lesquels marchent.

---

## 1. Hooks (0–3 s)

Le hook combine trois couches : **visuel** (ce qu'on voit à 0,0 s), **texte à l'écran**, **audio** (première phrase ou premier son). Les meilleurs alignent les trois sur la même promesse.

| Code | Hook | Formule type |
|------|------|--------------|
| `H-CURIO` | Boucle de curiosité | « Personne ne parle de ça mais… », « Regarde jusqu'à la fin » |
| `H-ERREUR` | Erreur / tu fais mal | « Arrête de [faire X] », « Tu fais encore [X] ? » |
| `H-RESULTAT` | Résultat d'abord | Montrer le résultat final / l'avant-après dès 0 s, puis expliquer |
| `H-CHIFFRE` | Chiffre / liste | « 3 trucs que… », « J'ai testé 7 [X] » |
| `H-POV` | POV / mise en situation | « POV : tu es [situation reconnaissable] » |
| `H-IDENTITE` | Appel d'identité | « Si tu es [type de personne], cette vidéo est pour toi » |
| `H-CLIVANT` | Opinion clivante | « [Opinion impopulaire] et je l'assume » |
| `H-DEFI` | Défi / pari | « J'ai [fait X] pendant 30 jours », « Est-ce que [X] marche vraiment ? » |
| `H-ACTION` | In medias res | Ça démarre au milieu de l'action, sans intro |
| `H-VISUEL` | Choc visuel | Image inattendue, satisfaisante ou absurde dès la 1re frame |
| `H-QUESTION` | Question directe | « Tu savais que… ? », « Pourquoi [X] ? » |
| `H-STORY` | Début d'histoire | « Le jour où [événement] … » |
| `H-REPONSE` | Réponse à un commentaire | Bulle « Répondre à @… » affichée à l'écran |

**Anti-hooks fréquents** : « Salut tout le monde, aujourd'hui… », logo/intro, écran noir, plan large sans sujet clair, texte trop long (> 12 mots), hook qui n'a rien à voir avec la suite.

## 2. Formats

| Code | Format |
|------|--------|
| `F-FACECAM` | Face caméra, parole directe |
| `F-VOIXOFF` | B-roll + voix off |
| `F-TEXTE` | Texte à l'écran sur un plan (souvent fixe) + son tendance |
| `F-TUTO` | Tutoriel étape par étape |
| `F-AVANTAPRES` | Transformation avant/après |
| `F-LISTE` | Top / liste / classement |
| `F-SKETCH` | Sketch / jeu de rôle / POV joué |
| `F-VLOG` | Day in my life / coulisses |
| `F-GREENSCREEN` | Fond vert (capture, article, image) + réaction |
| `F-DUO` | Duo / stitch / réaction à une autre vidéo |
| `F-SATISF` | Satisfaisant / ASMR / process |
| `F-DIAPO` | Carrousel photo |
| `F-TREND` | Trend audio/danse/format repris |
| `F-INTERVIEW` | Micro-trottoir / interview |

## 3. Structures de rétention

| Code | Structure | Déroulé |
|------|-----------|---------|
| `S-PROMESSE` | Promesse → preuve → payoff | Hook promet un résultat, étapes, résultat montré à la fin |
| `S-LISTE-CRESC` | Liste en crescendo | Le meilleur point est gardé pour la fin (« le n°1 va te choquer ») |
| `S-PROBLEME` | Problème → agitation → solution | Douleur, pourquoi c'est pire que tu crois, la solution |
| `S-RETOURN` | Retournement | Mise en place attendue puis twist |
| `S-AVANTAPRES` | Transformation | Avant, process accéléré, après (souvent montré aussi en hook) |
| `S-BOUCLE` | Boucle parfaite | La dernière frame/phrase s'enchaîne avec la première → revisionnages |
| `S-SERIE` | Épisode / partie N | « Partie 2 », cliffhanger, pousse à suivre le compte |
| `S-STORY` | Histoire en 3 actes | Situation, complication, chute |
| `S-REVEAL` | Révélation retardée | Info cachée, montrée seulement à la fin |

---

## 4. Texte à l'écran

À relever : nombre de mots du hook, taille, position (évite la zone basse couverte par la légende et la zone droite couverte par les boutons), sous-titres dynamiques oui/non, emojis, fautes volontaires, majuscules.

Patterns fréquents :
- `T-COURT` : hook ≤ 8 mots, gros, centré, lisible en < 1 s
- `T-SOUSTITRES` : sous-titres mot à mot synchronisés à la voix
- `T-PROGRESSION` : compteur ou étapes (« 1/5 », « jour 12 ») qui donnent envie d'aller au bout
- `T-COMMENT` : bulle de commentaire ou de question en guise de hook

---

## 5. Son / musique

| Code | Usage du son |
|------|--------------|
| `M-TREND` | Son tendance (beaucoup de vidéos l'utilisent en ce moment) |
| `M-ORIGINAL` | Son original (voix du créateur) |
| `M-SYNC` | Coupes/transitions calées sur le beat ou le drop |
| `M-DROP-REVEAL` | Le drop arrive pile au moment de la révélation |
| `M-FOND` | Musique de fond discrète sous une voix off |
| `M-AUDIOMEME` | Audio mème / réplique connue détournée |
| `M-SFX` | Effets sonores (whoosh, ding, rire) pour ponctuer |
| `M-SILENCE` | Silence / ASMR, son naturel |

À noter pour chaque son : nom exact affiché, original ou repris, énergie (calme / moyen / énergique), présence d'un drop et à quelle seconde. Un même son qui revient dans plusieurs outliers récents = **opportunité tendance**, à utiliser vite (souvent quelques jours à quelques semaines).

## 6. Leviers émotionnels (« dopamine »)

| Code | Levier | Action qu'il déclenche le plus |
|------|--------|-------------------------------|
| `E-CURIO` | Curiosité / suspense | Visionnage complet |
| `E-UTILE` | Utilité / « à garder » | Favoris |
| `E-IDENTIF` | Identification (« c'est tellement moi ») | Partages, identifications d'amis |
| `E-RIRE` | Humour | Partages |
| `E-INDIGN` | Indignation / débat | Commentaires |
| `E-ENVIE` | Envie / aspiration | Favoris, abonnements |
| `E-SATISF` | Satisfaction / ASMR | Revisionnages |
| `E-FOMO` | Peur de rater | Favoris, commentaires |
| `E-SURPRISE` | Surprise / choc | Revisionnages, partages |
| `E-EMOTION` | Émotion forte (tendresse, nostalgie) | Partages |

Les vidéos les plus fortes empilent souvent 2 leviers (ex. `E-UTILE` + `E-IDENTIF`).

---

## 7. Autres variables à relever

- **Durée** : < 10 s, 10–20 s, 20–40 s, 40–60 s, > 60 s
- **Rythme** : nombre approximatif de coupes, plan le plus long
- **Visage** dans la première seconde : oui/non
- **Légende** : longueur, question, mots-clés (TikTok est aussi un moteur de recherche : mots-clés dans le texte à l'écran, la voix et la légende)
- **Hashtags** : nombre, niche vs large
- **CTA** : type (« partage à… », « enregistre », « commente X », « partie 2 ? »)
- **Date de publication** si visible (une vidéo récente avec beaucoup de vues = signal fort)
